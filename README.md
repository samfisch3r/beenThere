# Been There

Been There is an Android application that helps you keep track of places you've visited.

## Features

- **Map Integration**: View your location and pinned places using [osmdroid](https://github.com/osmdroid/osmdroid).
- **Local Persistence**: Save your places securely using [Room Persistence Library](https://developer.android.com/training/data-storage/room).
- **Modern UI**: Built with [Jetpack Compose](https://developer.android.com/jetpack/compose) and Material 3 Design.
- **Asynchronous Operations**: Uses Kotlin Coroutines for smooth background data handling.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Database**: Room
- **Networking**: OkHttp
- **Map Engine**: OpenStreetMap (osmdroid)
- **Dependency Management**: Gradle Version Catalog (libs.versions.toml)

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio (Ladybug or newer recommended).
3. Build and run the `:app` module.
